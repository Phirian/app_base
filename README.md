
# 📱 Taskp!

Una aplicación Android desarrollada en Java en el IDE **Android Studio** que permite gestionar tareas de forma sencilla. Ideal para usuarios que desean organizar sus pendientes y marcar lo que ya han completado.

---

## ✨ Funcionalidades

- ✅ **Agregar tareas**: Crea nuevas tareas con nombre, descripción, fecha y prioridad
- 📋 **Visualizar tareas pendientes**: Lista todas las tareas que aún no han sido completadas.
- ✔️ **Marcar tareas como completadas**: Cambia el estado de una tarea cuando ya ha sido realizada, actualizando en tiempo real el estado de la tarea
- ✅ **Revisa el progreso de tu avance en las tareas diarias

---

## 🛠️ Tecnologías utilizadas

- **Lenguaje**: Java
- **IDE**: Android Studio
- **Base de datos**: SQLite

---

## 🚀 Cómo ejecutar el proyecto

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Phirian/app_base.git
   ```
2. Abre el proyecto en Android Studio.
3. Ejecuta la app en un emulador o dispositivo físico.

---

## 📌 Notas adicionales

- La app está diseñada para funcionar en dispositivos Android desde la versión 7.0
- No requiere conexión a internet.
